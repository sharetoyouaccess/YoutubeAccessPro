คู่มือการใช้งาน YouTube Access Pro สำหรับ NVDA

เวอร์ชัน 2026.08.25  ·  ผู้พัฒนา: Peem Narkkhwan

YouTube Access Pro เป็นโปรแกรมเสริมสำหรับ NVDA ที่ให้ผู้ใช้สามารถค้นหา เล่น และดาวน์โหลดเนื้อหาจาก YouTube ได้อย่างเต็มรูปแบบ ควบคุมการทำงานทั้งหมดด้วยแป้นพิมพ์โดยไม่ต้องพึ่งเมาส์ พร้อมรองรับการอ่านสถานะโดย NVDA ตลอดการใช้งาน

สารบัญ
  1. ความต้องการของระบบ
  2. การเปิดและปิดหน้าต่าง
  3. โครงสร้างหน้าต่างหลัก
  4. แท็บ Search and Download
  5. แท็บ Playlists
  6. แท็บ Subscriptions (ติดตามช่อง)
  7. คีย์ลัดทั่วทั้งระบบ (Global Hotkeys)
  8. แท็บ Settings
  9. การแก้ปัญหาเบื้องต้น

1. ความต้องการของระบบ

  • NVDA เวอร์ชัน 2025.3 ขึ้นไป
  • ไฟล์ mpv และ yt-dlp ที่แนบมากับโปรแกรมเสริมนี้ (ติดตั้งมาให้พร้อมใช้งานแล้ว ไม่ต้องดาวน์โหลดเพิ่ม)
  • การเชื่อมต่ออินเทอร์เน็ต

2. การเปิดและปิดหน้าต่าง

การกระทำคีย์ลัด
เปิดหน้าต่างโปรแกรมNVDA+Y
เปิดจากเมนู Tools ของ NVDAเมนู NVDA → Tools → YouTube Access Pro
ซ่อนหน้าต่าง (การเล่นเสียงยังคงดำเนินต่อไป)Escape
ออกจากโปรแกรมปุ่ม Exit ในแต่ละแท็บ หรือ Alt+F4
หมายเหตุ: การซ่อนหน้าต่างไม่หยุดเพลง — เพลงจะเล่นต่อไปในพื้นหลัง หากมีการดาวน์โหลดค้างอยู่ ระบบจะแสดงกล่องยืนยันก่อนออกจากโปรแกรมเสมอ ไม่ว่าจะออกด้วยปุ่ม Exit หรือ Alt+F4
การนำทางด้วย Tab: การกด Tab จะหยุดอยู่ที่ปุ่ม Exit และไม่วนกลับไปจุดเริ่มต้น หากต้องการย้อนกลับให้กด Shift+Tab

3. โครงสร้างหน้าต่างหลัก

หน้าต่างหลักประกอบด้วย 4 แท็บ สลับแท็บด้วย Ctrl+Tab / Ctrl+Shift+Tab หรือกด Ctrl+1 ถึง Ctrl+4 เพื่อไปยังแท็บนั้นโดยตรงตามลำดับต่อไปนี้:

  1. Search and Download — ค้นหา เล่น และดาวน์โหลด
  2. Playlists — จัดการเพลย์ลิสต์ส่วนตัว
  3. Subscriptions — ติดตามช่อง YouTube และเรียกดูเนื้อหาแบบ Videos, Shorts, Live, Playlists
  4. Settings — ตั้งค่าการทำงานของโปรแกรม

กด Ctrl+F จากตำแหน่งใดก็ได้ในหน้าต่างเพื่อไปยังช่องค้นหาโดยตรง

ความช่วยเหลือด่วน: กด Ctrl+F1 ในแท็บใดก็ได้ เพื่อให้โปรแกรมอ่านสรุปวิธีใช้งานและคีย์ลัดของแท็บนั้นทันที เหมาะสำหรับผู้เริ่มใช้งานที่ยังไม่คุ้นเคยกับคู่มือฉบับเต็ม (คีย์ F1 เพียงอย่างเดียวยังคงทำหน้าที่ดาวน์โหลดเป็นเสียงตามปกติ ไม่ได้ถูกแทนที่)
การเปลี่ยนภาษาของโปรแกรม: กด Ctrl+T จากตำแหน่งใดก็ได้ในหน้าต่างเพื่อสลับภาษาที่โปรแกรมแสดงผลและอ่านออกเสียงระหว่างไทยกับอังกฤษ การตั้งค่านี้แยกจากภาษาของ NVDA เอง จึงไม่จำเป็นต้องเปลี่ยนภาษาของ NVDA เพื่อใช้งานโปรแกรมเป็นภาษาไทย ภาษาที่เลือกไว้จะถูกจดจำและใช้ในการเปิดครั้งถัดไปโดยอัตโนมัติ

4. แท็บ Search and Download

4.1 ช่องค้นหา (Search text or paste a link)

  • พิมพ์คำค้นหา หรือวางลิงก์วิดีโอ/เพลย์ลิสต์จาก YouTube โดยตรง
  • กด Enter หรือกดปุ่ม "Search or open link" เพื่อเริ่มค้นหา
  • เมื่อค้นหาด้วยคำและประเภทเดิมซ้ำ ปุ่มจะเปลี่ยนข้อความเป็น "Clear search field"

4.2 ประเภทการค้นหา (Search type)

  • Video — ค้นหาวิดีโอทั่วไป
  • Playlist — ค้นหาเพลย์ลิสต์
  • Channel — ค้นหาช่องโดยตรงจากชื่อ โดยไม่ต้องค้นหาวิดีโอของช่องนั้นก่อน
  • Live — ค้นหาเฉพาะวิดีโอที่กำลังถ่ายทอดสดอยู่ในขณะนั้นตามคำค้นหา

เมื่อโฟกัสอยู่ที่ตัวเลือก Search type สามารถกด Enter เพื่อเริ่มค้นหาได้ทันที

การเปิดผลลัพธ์ที่เป็นช่อง (ทั้งจากการค้นหาแบบ Channel และจากการเลือกชื่อผู้อัปโหลดในผลลัพธ์อื่น) จะแสดงรายการคลิปของช่องนั้นในลิสต์เดียวกัน เช่นเดียวกับการเปิดเพลย์ลิสต์ กด Ctrl+S ที่แถวของช่องเพื่อติดตามช่องนั้นได้ทันที โดยไม่จำเป็นต้องเปิดดูคลิปก่อน
วิดีโอที่กำลังถ่ายทอดสด: เมื่อกด Enter เล่นวิดีโอที่กำลังถ่ายทอดสดอยู่ (ไม่ว่าจะมาจากผลค้นหาหมวด Live, หมวด Live ในแท็บ Subscriptions หรือวางลิงก์โดยตรง) โปรแกรมจะเปิดวิดีโอนั้นในเบราว์เซอร์เริ่มต้นของเครื่องแทนการเล่นในโปรแกรมนี้ เนื่องจากตัวเล่นวิดีโอของเบราว์เซอร์เองรองรับการถ่ายทอดสดได้เสถียรกว่า วิดีโอที่บันทึกไว้แล้ว (ไม่ใช่การถ่ายทอดสด) ยังคงเล่นในโปรแกรมนี้ตามปกติ

6. แท็บ Subscriptions (ติดตามช่อง)

ใช้ติดตามช่อง YouTube ที่ชื่นชอบ แล้วเรียกดูเนื้อหาของช่องนั้นในรูปแบบเดียวกับ YouTube เอง คือแบ่งเป็นหมวด Videos, Shorts, Live และ Playlists โดยไม่ต้องค้นหาชื่อช่องซ้ำทุกครั้ง

วิธีเริ่มติดตามช่อง: ไปที่แท็บ Search and Download ค้นหาคลิปของช่องที่ต้องการ (หรือค้นหาแบบ Channel โดยตรง) แล้วกด Ctrl+S ที่รายการนั้น

6.1 รายการช่องที่ติดตาม

คีย์ลัดการทำงาน

F1ดาวน์โหลดคลิปล่าสุดทั้งหมดของช่องนี้เป็นไฟล์ MP3
F2ดาวน์โหลดคลิปล่าสุดทั้งหมดของช่องนี้เป็นไฟล์ MP4

6.2 การไล่ดูหมวดหมู่ของช่อง

เมื่อกด Enter บนช่องในรายการหัวข้อ 6.1 รายการทางขวาจะแสดงหมวดของช่องนั้นก่อน ได้แก่ Videos, Shorts, Live และ Playlists กด Enter บนหมวดใดเพื่อเปิดดู

  • การเปิด Videos, Shorts หรือ Live จะแสดงรายการคลิปของหมวดนั้นโดยตรง พร้อมเล่นหรือดาวน์โหลดได้ทันที
  • การเปิด Playlists จะแสดงเพลย์ลิสต์ทั้งหมดของช่องนั้น กด Enter บนเพลย์ลิสต์ใดอีกครั้งเพื่อเปิดดูคลิปภายใน
  • กด Backspace เพื่อย้อนกลับขึ้นไปหนึ่งชั้นได้ทุกเมื่อ (จากรายการคลิปกลับไปหมวด จากคลิปในเพลย์ลิสต์กลับไปรายการเพลย์ลิสต์ และจากหมวดกลับไปรายการช่อง)

User Guide — YouTube Access Pro Add-on for NVDA

Version 2026.08.25  ·  Author: Peem Narkkhwan

YouTube Access Pro is an NVDA add-on that gives users full access to YouTube: searching, playing, and downloading content entirely from the keyboard, with complete NVDA speech feedback throughout.

1. Requirements

  • NVDA 2025.3 or later
  • The mpv and yt-dlp files bundled with this add-on (already included; no separate download needed)
  • An active internet connection

2. Opening and Closing the Window

ActionShortcut
Open the add-on windowNVDA+Y
Open from the NVDA menuNVDA Menu → Tools → YouTube Access Pro
Hide the window (playback continues)Escape
Exit the add-onExit button on any tab, or Alt+F4
Note: Hiding the window does not stop playback; audio continues in the background. If a download is still active, a confirmation dialog always appears before exiting, whether triggered by the Exit button or Alt+F4.
Tab navigation: Pressing Tab stops at the Exit button and does not wrap back to the start. Press Shift+Tab to navigate backwards.

3. Main Window Structure

The window contains four tabs. Switch between them with Ctrl+Tab / Ctrl+Shift+Tab, or press Ctrl+1 through Ctrl+4 to jump directly to a tab in this order:

  1. Search and Download — search, play, and download
  2. Playlists — manage local playlists
  3. Subscriptions — follow YouTube channels and browse their Videos, Shorts, Live, and Playlists
  4. Settings — configure the add-on

Press Ctrl+F from anywhere in the window to jump directly to the search field.

Quick help: Press Ctrl+F1 on any tab to have the add-on speak a summary of that tab's usage and shortcuts immediately — useful for new users who have not yet read the full guide. Plain F1 is unaffected and still downloads as audio.
Switching the add-on's language: Press Ctrl+T from anywhere in the window to switch the add-on's displayed and spoken language between Thai and English. This setting is independent of NVDA's own language, so NVDA does not need to be set to Thai to use the add-on in Thai. The selected language is remembered and used automatically the next time the window opens.

4. Search and Download Tab

4.1 Search Field

  • Type search keywords, or paste a YouTube video or playlist link directly.
  • Press Enter or the "Search or open link" button to begin.
  • When the same query and search type are already active, the button changes to "Clear search field".

4.2 Search Type

  • Video — search for individual videos
  • Playlist — search for playlists
  • Channel — search for a channel directly by name, without first finding one of its videos
  • Live — search only for videos that are currently live-streaming, matching the search text

When focus is on the Search type control, press Enter to search immediately.

Opening a channel result — whether from a Channel search or from an uploader name elsewhere — shows that channel's videos in the same list, the same way opening a playlist does. Press Ctrl+S on a channel row to subscribe to it immediately, without opening its videos first.
Currently-live videos: pressing Enter to play a video that is currently live-streaming (whether found via a Live search, the Subscriptions tab's Live section, or a pasted link) opens it in the system's default browser instead of playing it inside this add-on, since the browser's own video player handles live streaming more reliably. Videos that have already finished streaming (recordings, not currently live) still play inside this add-on as usual.
